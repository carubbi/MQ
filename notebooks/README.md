# Notebooks

Os notebooks diretamente nesta pasta estão em elaboração. As versões
finalizadas para consulta discente ficam em [`resolvidos/`](resolvidos/).

## Promoção de um notebook

A promoção ocorre sob demanda. Um notebook docente finalizado deve estar
diretamente em `prof/notebooks/` e ter nome iniciado por `u`, seguido do número
positivo da unidade e de `_`, como
`u2_s03_distribuicoes_discretas.ipynb`.

Depois da revisão, mova o arquivo para `notebooks/resolvidos/`, substitua
referências locais de imagens por URLs GitHub Raw, valide o JSON e atualize os
links públicos relacionados. Arquivos sem o prefixo de unidade permanecem em
`prof/notebooks/`.
